Portfolio – Privacy policy

For the game “Portfolio: Island Money Game” on Android, on Windows and in a web browser. Last updated: 16 October 2026 (version 1.2.0, online play). Latviski

In short

Portfolio has no accounts, no ads, no analytics and no tracking. Played on one device, it sends nothing over the internet. Only when you play an online game does it send what that game needs – the names and pictures the players choose and the moves of the game – to the game server, and that is deleted after the game.

What stays on your device

Your saved game, the family profiles (the names, colours and pictures you choose, levels, statistics and achievements) and your settings are kept only in the game's own storage on your device (on Android its private storage, on Windows the Documents\Portfolio folder, in a browser that browser's storage). The developer never receives them.

If Android's backup is turned on, Android may include these files in your own Google backup, so that they move with you to a new phone. That backup belongs to your Google account; the developer cannot see it.

Online games

An online game is played by people who share its game code with each other. To run it, the game sends to the game server:

  • the name each player types in or picks from a profile (we ask for a first name or a nickname), their picture and colour;
  • the moves of the game, and the game itself as it goes on;
  • a random code that lets your device come back to its seat (the server keeps only a scrambled form of it).

Your profile's level, statistics and achievements are never sent; they stay on your device. There is no chat, and only the people with the game code can join.

The game server runs on Cloudflare (Cloudflare, Inc., a service provider that processes the data for us). Like any internet service, Cloudflare sees your device's internet address while it delivers the connection; the game does not store it, and the game server keeps no logs with names or game codes.

How long: a finished game is deleted from the server one day after it ends; an unfinished game is deleted after 14 days without a move; a game that never started is deleted after one day. Nothing is shared with anyone else, sold, or used for anything but running that game.

Children

Portfolio is made for families and for ages 10 and up. Online games are only with people you invite, with no chat. Please use a first name or a nickname in online games. Nothing else is collected from anyone, children included.

Deleting your data

On your device: uninstall the game, or on Android open Settings → Apps → Portfolio → Storage → Clear storage (on Windows, delete the Documents\Portfolio folder; in a browser, clear the site's data). On the server: online games delete themselves as described above. To have a running online game deleted sooner, write to the e-mail address below with its game code.

Changes

If a later version sends anything more, this page will say first exactly what, why, where and for how long – before that version is released.
